## Launching

Run `y` in a terminal. `y` is a wrapper function in `~/.zshrc` that changes the
shell's directory to wherever yazi was when you quit. The plain `yazi` command
leaves the shell's directory unchanged. `q` quits; `Q` quits without changing
directory.

## Config files

| file | managed by | contents |
|---|---|---|
| `~/.config/yazi/yazi.toml` | yadm | Natural sort, directories first, size linemode, preview wrap, openers |
| `~/.config/yazi/keymap.toml` | yadm | Custom binding added to the stock keymap (see below) |
| `~/.config/yazi/theme.toml` + `flavors/` | home-manager | Nord flavor (`modules/home/yazi.nix`, `pkgs.yaziPlugins.nord`) |
| `~/.config/yazi/plugins/` | home-manager | Preview plugins and `extract-here.yazi` |

The flavor is set with `theme.flavor.dark = "nord"`. Upstream removed
`flavor.use`; yazi ignores it, so setting it loads no flavor. Icon colors come
from a Nord-mapped icon set, `icons-nord.toml`, generated by
`modules/home/icons-nord-gen.py`.

## Custom binding

`E` extracts the hovered or selected archive into the current directory. yazi's
built-in extract plugin has no binding of its own, so `plugins/extract-here.yazi`
calls it. The binding is a `prepend_keymap` entry in
`~/.config/yazi/keymap.toml`; all other keys are stock yazi v26.

## Stock bindings

| keys | action |
|---|---|
| `h` / `l` | Parent directory / enter directory or open file |
| `j` / `k` | Cursor down / up |
| `gg` / `G` | Go to top / bottom |
| `H` / `L` | Directory history back / forward |
| `Space` | Toggle selection · `v` visual mode |
| `y` / `x` / `p` / `P` | Yank / cut / paste / paste and overwrite |
| `d` / `D` | Trash / delete permanently |
| `a` / `A` | Create file (trailing `/` creates a directory) / bulk create |
| `r` | Rename; with several files selected, bulk rename in `$EDITOR` |
| `o` / `O` | Open / open with a chosen opener |
| `/`, `n`, `N` | Find by name, next / previous match (`?` finds backwards) |
| `s` / `S` | Search file names (fd) / file contents (ripgrep) |
| `f` | Filter the listing |
| `z` / `Z` | Jump with fzf / zoxide |
| `.` | Toggle hidden files |
| `t t` / `1–9` / `[` `]` | New tab / go to tab / previous, next tab |
| `w` | Open task manager (watch or cancel running operations) |
| `K` / `J` | Scroll preview |
| `;` / `:` | Run shell command (async / blocking) |
| `~` | Show help with the full stock keymap |

To bulk rename, select the files and press `r`: yazi opens the names in
`$EDITOR` and applies the changes when you save and quit.

## Previews and openers

Preview plugins (installed by home-manager): glow (Markdown), piper
(docx/odt/epub via pandoc), rich-preview (rst/ipynb), miller (csv/tsv), duckdb
(parquet/xlsx/db), mediainfo (audio, subtitles), lsar (rar), allmytoes (XDG
thumbnails), mime-ext (extension-based fallback). PDF, HEIC, SVG and fonts use
yazi's built-in previewers.

`Enter` / `o` open files by MIME type: documents (pdf, epub, cbz/cbr) in
zathura, images in loupe, media in mpv. `modules/home/zathura.nix` also
registers zathura as the system default for these document types, so
`xdg-open` uses it too.

## zathura

zathura is a vi-style document viewer. Its mupdf backend handles PDF, EPUB,
CBZ/CBR, DjVu and PS. Colors come from the shared Nord palette
(`modules/home/zathura.nix`).

| keys | action |
|---|---|
| `j` / `k` | Scroll · `J` / `K` next / previous page |
| `h` / `l` | Scroll sideways · `H` / `L` jump to page edge |
| `gg` / `G` | First / last page · `<n>G` go to page n |
| `/` | Search · `n` / `N` next / previous match |
| `Tab` | Show index (table of contents) |
| `r` | Rotate · `a` / `s` fit page / fit width |
| `:` | Command line (`:open`, `:print`, `:set`) |

The [zathura app page](../apps/zathura.html) has the full stock keymap.
